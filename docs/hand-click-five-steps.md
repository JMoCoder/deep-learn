# Deep Learn 手点：五步 + 拒回流 + 引用 + 大纲卡

验收入口：`docker compose up --build` → PWA http://127.0.0.1:43127  
学习页会话顶和正文下有「银时手点」条，随相位换提示。

用户可见名：**Deep Learn**。内部包名仍是 Quantum，不要在手点里改包名，也不要背策略枚举。

看行为，不看内部策略名。过线看：边界卡 → **大纲卡** → 引用行 → 笔记只读 → 导出 → **拒 + 回流**。

## 五步

1. **新建 → 边界卡**  
   书籍 → 右侧抽屉 → **新建主题**。先说想学什么（主题锚点），再答齐 8 维（动机 → 终点 → 成功证据 → 先验 → 先修 → 必须包含 → 排除 → 深度 → 负荷）。等学习页**独立边界卡**，点「确认边界，看大纲」。未确认时不要在会话里回「可以」。

2. **大纲卡确认 → 学习**  
   学习页出现**确认大纲**卡（不是另开计划页）。看每叶 **objective**、**先修「A → B」**（标题，不是 raw id）、篇幅。确认用卡上的「确认大纲，开始学习」。超负荷预算时点卡上的重拟，**不要**在会话里回「可以」或「减叶」。确认后进学习；左栏大纲同样列出先修边。

3. **右栏追问 + 引用**  
   顶栏右开会话。问当前节（「这段在讲什么」）。有正文时应出现**引用行**（可点进该节）。空引用不出现。助手应指回落盘要点，而不是另起一套百科。

4. **笔记只读**  
   助手写入笔记后，书籍页笔记只读；类型是思考 / 疑问 / 拓展。没有「记一笔」。笔记不是整段聊天拷贝。

5. **导出**  
   书籍历史卡导出 **html**（或 md / epub）。应收到可打开的下载，不是空壳成功。

## 抽测（行为，不背枚举）

- **推进下一叶**：学习相位说「下一节」。应投影 / 指向下一叶，而不是只回一句空话。  
- **还没有正文**：还在大纲或第一节尚未投影时，助手应搭台阶、引导生成，不假装已经读过盘。  
- **拒 + 回流**：踩排除区（如排除「弦论」时说「顺便把弦论也讲一遍」）→ 出现拒回流（短拒 + 拉回当前节）。该轮书籍笔记不增加，也不出现引用行。

客户端仍只订 7 个域名 SSE。拒回流骑在会话消息上，不新开事件名。
