# 银时手点：五步 + ADVANCE + 拒回流

验收入口：`docker compose up --build` → PWA http://127.0.0.1:43127  
学习页会话顶和正文下有「银时手点」条，随相位换提示。

## 五步

1. **新建 → 边界卡**  
   书籍 → 右侧抽屉 → **新建主题**。答齐 8 维（动机 → 终点 → 成功证据 → 先验 → 先修 → scope_in → 排除 → 深度 → 负荷）。等独立边界卡，点「确认边界，看大纲」。未确认时不要回「可以」。

2. **大纲确认 → 学习**  
   看每叶 **objective**、**先修「A → B」**（标题，不是 raw id）、篇幅。确认后进 `learning`。左栏大纲同样列出先修边。

3. **右栏追问**  
   顶栏右开会话。问当前节（「这段在讲什么」）。应见 **策略行**（GROUND 等）和 **CiteRow**。有正文时 cite 可点进该节。空 cite 不出现。

4. **笔记只读**  
   助手 `append_note` 后，书籍页笔记只读，reason_code → 思考/疑问/拓展。没有「记一笔」。

5. **导出**  
   书籍历史卡导出 **html**（或 md/epub）。应收到下载。

## 抽测

- **ADVANCE**：学习相位说「下一节」。策略行应为 `ADVANCE`，并投影下一叶。  
- **SCAFFOLD**：大纲起草或第一节尚未投影时，策略行可为 `SCAFFOLD`。  
- **2.7 拒回流**：踩 `scope_out`（如排除「弦论」时说「顺便把弦论也讲一遍」）→ `REFUSE_OFFSCOPE`，短拒 + 拉回当前节，书籍笔记不增加。

客户端仍只订 7 个域名 SSE；策略走 `message.strategy`，不新开 domain event。
